STEINS;GATE (PS VITA, PCSE00644) : TRADUCTION FRANÇAISE
Patch de fan, gratuit et non officiel. Il ne fonctionne qu'avec le jeu : vous devez le posséder.

Ce patch traduit l'histoire, les messages du téléphone, les pièces jointes, les TIPS et les menus,
les images de l'interface, le tableau de Kurisu, les images de journaux télévisés,
et les sous-titres de trois vidéos.
Version de test : seuls le prologue et une partie des menus ont été vérifiés sur console.

INSTALLATION
1. Installez le plugin rePatch sur votre Vita, si ce n'est pas déjà fait.
2. Copiez le dossier « rePatch » à la racine de ux0:
3. Lancez le jeu.

Vous devez obtenir :
  ux0:rePatch/PCSE00644/gamedata/script.cpk
  ux0:rePatch/PCSE00644/gamedata/system.cpk
  ux0:rePatch/PCSE00644/gamedata/bg.cpk
  ux0:rePatch/PCSE00644/gamedata/movie.cpk
Il faut environ 660 Mo d'espace libre sur la carte.

DÉSINSTALLATION
Supprimez ux0:rePatch/PCSE00644/ sur la Vita. Le jeu installé n'est jamais modifié.
